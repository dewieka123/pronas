# Pro NAS – Local Network Attached Storage with Web Terminal

**Pro NAS** is a lightweight, self‑hosted file manager and remote shell tool that runs entirely on your local machine.  
It gives you a clean web dashboard to **browse, upload, download, copy, move, rename, and delete files** – just like a personal cloud drive.  
Plus, it comes with a built‑in **web terminal** that lets you run system commands directly from your browser.

Everything is stored in a folder of your choice on your computer. No third‑party services, no subscriptions – just your files, your control.

---

## ✨ Features

- **File Explorer** – View folders and files in a grid layout.
- **Upload** – Select multiple files at once and upload them to the current folder.
- **Download** – Download any file with one click (folders are not yet supported for download).
- **Preview** – Quickly preview images, videos, and audio files without leaving the browser.
- **Context Menu** – Right‑click on any item to:
  - Preview
  - Download
  - Rename
  - Copy / Cut
  - Delete
- **Clipboard** – Copy or cut items and paste them elsewhere (works across folders).
- **Create Folder** – Make new directories from the dashboard.
- **Breadcrumb Navigation** – Click on any part of the path to jump back.
- **Web Terminal** – Open a command‑line interface inside your browser and run any system command (Windows CMD) – useful for advanced users.
- **Persistent Storage** – All files are stored in a folder you specify (default: `C:\Users\Admin\Project\Drive Cloud`).
- **Cross‑Platform** – Runs on any system with Python 3 (tested on Windows, but compatible with Linux/macOS with minor adjustments).

## 🚀 Getting Started

### Requirements
- Python 3.6 or later (download from [python.org](https://python.org))
